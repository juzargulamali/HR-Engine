## Find a project in the Projects list
- id: projects-directory
- area: projects
- status: published
- keywords: find a project; projects list; project directory; search projects; filter projects; completed projects; archived projects; project board; next milestone; unread; summary only; who is the project manager
- links: Projects -> /projects; My Work -> /projects/work
- screens: /projects

The Projects page lists every project you can see, with its Project Manager, status and key dates. Needs you at the top links to handovers, reviews, overdue tasks and unread chat that wait for you. A project you work on opens in full; any other project opens a short summary beside the list, because its plans, chat and files are for its team. The Next milestone column is filled only for projects you are part of.

1. Open Projects & Tasks, then Projects.
2. Type in the search box to find a project by name, reference or Project Manager.
3. Use Show to switch between Ongoing and Completed and archived, and Kind, Status or Company to narrow the list. Press Clear to remove the filters.
4. Click a column heading such as Key dates or Status to sort, or choose Board to see the ongoing projects by status.
5. Click a project to open it. All projects on the project brings you back to the same list.

## Start an internal project
- id: projects-new-internal
- area: projects
- status: published
- keywords: new internal project; create a project; add a project; internal project; accountable owner; project reference code; set code; ongoing work; showroom project; no client project
- links: Projects -> /projects; New internal project -> /projects/new
- screens: /projects/new; /projects

An internal project is for work with no client and no Sales enquiry, such as showroom technology or maintenance. Only a founder, or someone a founder allowed to assign Project Managers, can create one; everyone else does not see the button. The person you name as accountable owner becomes its Project Manager. Client projects are never created here: they start when a Project Manager accepts a Sales handover. Pressing Create project twice makes two projects, so press it once.

1. Open Projects and press New internal project.
2. Enter the Project name and choose the Accountable owner. With more than one company, choose the Company first.
3. Open Add more details if you want a Start date, End date, Ongoing work or a Brief.
4. If the form says the company has no project reference code yet, a founder sets it with Set code first.
5. Press Create project. The new project opens in Planning.

## Change a project's status, put it on hold or reopen it
- id: projects-status
- area: projects
- status: published
- keywords: change status; move project; put on hold; hold a project; resume project; review date; archive project; reopen project; edit project details; manage project; project dates; move card on board
- links: Projects -> /projects
- screens: /projects; /projects/[id]/work

The Project Manager, a temporary project leader or a founder changes a project's status from Manage project in the project header. The Project Manager or a founder can also move its card on the Projects board. One stage forward needs nothing more; going back or skipping a stage needs a reason; a hold needs a reason and a review date. Completing has its own page, Complete project. Reopening a completed project is only for founders and people a founder allowed to reopen.

1. Open the project, press Manage project and choose Change status. Or on Projects choose Board and use Move to on the card.
2. Choose where it moves under Move to, fill in the Reason, or Why is it on hold? and Review date, and press Save status.
3. To bring a held project back, choose Resume: it returns to the stage it was held from.
4. To change the name, dates, location or priority, choose Manage project, then Edit details, and press Save details.
5. To reopen a completed project, choose Manage project, then Reopen project, say why, and press Reopen.

## The project calendar
- id: projects-calendar
- area: projects
- status: published
- keywords: project calendar; my calendar; company calendar; task deadlines; review requests; milestones; site bookings; month view; week view; agenda; time zone; project dates; project spans
- links: Calendar -> /projects/calendar; My Work -> /projects/work
- screens: /projects/calendar

Calendar has two views. My calendar shows your own task deadlines, the reviews waiting for you, the milestones of projects you are on and the site bookings made for you. Company calendar shows only each project's reference, name, status and start and end dates, never its tasks or bookings. Nothing can be changed here: click an entry to open the project and change it there. Deadlines are plain dates; timed site bookings show the site's own time first.

1. Open Projects & Tasks, then Calendar.
2. Choose My calendar or Company calendar.
3. Choose Month, Week or Agenda, and use the arrows or Today to move through time.
4. On My calendar, tick what to show under Show only, choose a zone under Show times in, and press Apply.
5. Click an entry to open its project.
