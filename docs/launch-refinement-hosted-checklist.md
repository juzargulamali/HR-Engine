# Launch refinement: hosted verification checklist (read-only)

What local testing **cannot** establish, to be checked by the owner on **Enginious HR Engine_V2** and on Vercel. Install order: `docs/launch-refinement-install-order.md`. Local evidence: `docs/launch-p3-deployment.md`, section "Local verification".

**Rules for every check.** Previews and the hosted app use the **live** V2 database. On a preview, only **look**: do not create sample projects or enquiries, move stock, record a dispatch or return, enable any switch, or save anything. SQL is only the `*_00_preflight_readonly.sql`, `*_05_*` and `*_20_verify_readonly.sql` files (SELECT only). The three optional writing files (`deact_30_...`, `inv_notes_30_...`, `inv_notes_80_...`) are **not** part of this checklist and stay unrun.
